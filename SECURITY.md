# Security Policy

## Supported versions

Security fixes are provided for the latest version of the `main` branch.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Create a private report through GitHub Security Advisories for this repository. Include:

- A description of the issue and affected component.
- Steps to reproduce or a minimal proof of concept.
- Any relevant logs or sample files, with credentials and personal data removed.
- Your assessment of potential impact.

You will receive an acknowledgment after the report is reviewed. Please allow reasonable time for investigation and for a fix to be prepared before public disclosure.

## Scope

NCICParser processes text files and exports CSV output. Reports concerning parser crashes, denial of service, unsafe file handling, or sensitive data exposure are in scope. Test fixtures and example data should not contain real credentials or personal information.
